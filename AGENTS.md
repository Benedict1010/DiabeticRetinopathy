# Diabetic Retinopathy Prototype

This repository contains a B.Tech final-year prototype for diabetic-retinopathy research. The frontend lives in `frontend/` and is a standalone React/Vite user-interface prototype.

## Frontend-only rules

- During UI work, create and modify files only inside `frontend/`.
- Do not modify `backend/`, `model/`, `dataset/`, `preprocessing/`, `notebooks/`, `saved_models/`, `uploads/`, `reports/`, `assets/`, or existing ML files.
- The current frontend uses mock/demo analysis data. Do not represent it as live clinical inference.

## Frontend commands

From `frontend/`:

```powershell
npm install
npm run dev
npm run build
```

Do not change ML training, model architecture, model weights, preprocessing, datasets, or evaluation code while implementing the UI.
